개발은 기능을 만드는 것에서
끝나지 않는다고 생각합니다.

사용자가 실제로 사용하는 서비스의 흐름을 이해하고, 운영 과정에서 생기는 문제까지 해결하는 개발을 지향합니다.

저는 문제가 생겼을 때 원인을 찾고 직접 해결하는 과정을 좋아합니다. 단순히 화면을 구현하는 것뿐만 아니라 데이터 흐름, 서버 로직, 외부 API, 결제, 모바일 WebView와 배포 환경까지 연결해서 생각하려고 합니다.

특히 NicePayments PG 연동 및 부분취소, React Native WebView 기반 앱 개발, 웹과 앱 사이의 메시지 처리, 외부 API 연동 등 웹을 넘어 실제 서비스가 동작하는 환경까지 직접 다뤄왔습니다.

Java/Spring 교육과 팀 프로젝트를 통해 객체지향, MVC, MyBatis, JSP, AJAX 등의 기본기를 익혔고, 이후 PHP/MySQL 기반 실무에서 빠르게 요구사항을 파악하고 기능으로 연결하는 경험을 쌓았습니다.
